
# GameVerse

A Flask-powered browser game launcher with a Steam-inspired design.

## Run locally

Install dependencies:

    pip install -r requirements.txt

Start the server:

    python app.py

Open http://127.0.0.1:5000

## Blitz deployment

Upload app.py, requirements.txt, README.md, and the templates folder.

Use this start command:

    python app.py

The application binds to 0.0.0.0 and uses the PORT environment variable.

## Features

- Game cards and categories
- Search
- Favorites saved in the browser
- Minecraft-style browser game links
- Responsive layout
